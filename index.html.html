Importação e backup

Exporte todos os seus dados para um arquivo JSON. Para importar, selecione um backup do Beeztrô ou um CSV de receitas no formato indicado abaixo.

Formato CSV: colunas nome,categorias,rendimento,unidade_rendimento,ingredientes,preparo,observacoes. Na coluna ingredientes, separe cada item com |, no formato nome:quantidade:unidade. Ex.: Grão-de-bico:500:g|Sal:10:g.

Importações são revisadas e confirmadas antes de substituir ou acrescentar dados. Faça backups frequentes.
